# 脚本降级输出规则

## 目标

当安装后的 Skill 缺少脚本或运行环境不可用时，继续给用户可读、可复制、可执行的纯文本结果。降级输出不能假装已经生成真实图片、HTML 文件或本地路径。

## 不可用范围

以下任一情况都视为脚本不可用：

- scripts/ 目录缺失。
- `scripts/generate_images.py` 或 `scripts/generate_review_report.py` 缺失。
- python3 不存在或无法执行。
- prompts/review JSON 输入文件缺失或无法读取。
- 脚本执行返回错误。
- 输出目录无法创建、无写入权限或文件写入失败。
- 运行环境不允许调用本地命令。

脚本不可用时：

- 明确说明未生成真实图片或 HTML 文件。
- 不终止任务，不要求用户先修环境才能继续。
- 直接提供降级版结果，并给出可选的后续修复提示。

## 生图降级

触发：用户要求直接生图，但 `generate_images.py`、Python 环境、配置、输入或输出目录不可用。

处理：

1. 继续输出完整图文笔记。
2. 图片部分改为 `ASCII 示例图 + Prompt + 使用说明`。
3. 每张图用固定宽度 Markdown 代码块展示示意画面。
4. 明确标注：`这是示意图，不是真实生成图片。` 也可写作 `这只是示意图，不是真实生成图片。`

ASCII 示例图模板：

```markdown
# 图片
1. 图1：封面图
   - 使用：ASCII 示例图（这是示意图，不是真实生成图片）
   - 画面要点：主体、场景、构图、情绪、留白区
   - Prompt：[可复制给生图模型的完整 Prompt]

```text
+------------------------------------------------+
|                  封面标题区                    |
|             [大字标题 / 关键词]                |
|                                                |
|        ________                                |
|       /        \        主体：产品/人物/场景    |
|      |  MAIN    |                              |
|       \________/                               |
|                                                |
|  细节区：道具 / 步骤 / 氛围 / 色彩             |
|  留白区：适合后期添加小红书封面字              |
+------------------------------------------------+
```
```

输出要求：

- 教程型：ASCII 图中体现步骤编号、材料区、完成图。
- 探店型：ASCII 图中体现门头/环境/招牌/菜品位置。
- 好物型：ASCII 图中体现产品主体、使用场景和细节放大区。
- 知识卡片型：ASCII 图中体现标题区、三栏信息或清单结构。
- 不要用 ASCII 图替代 Prompt；Prompt 必须保留。

## 复盘报告降级

触发：用户要求 HTML 看板，但 `generate_review_report.py`、Python 环境、review JSON 或输出目录不可用。

标题固定为：

```markdown
## 发布后复盘报告（Markdown 降级版）
```

开头说明：

```markdown
未生成真实 HTML 文件：当前环境中 [原因]。以下为纯文本降级版报告，已保留数据结论、流量漏斗、封面标题点击诊断、目标人群与关键词匹配、当前补救动作和下一篇实验卡。
```

### 必要数据说明

如果缺少小眼睛/观看数，先追问用户：

```markdown
我没有拿到小眼睛/观看数，这会影响流量判断。请补充观看数，或回复“跳过”继续做不完整复盘。
```

用户明确跳过后，报告开头必须写：

```markdown
不完整流量诊断：缺少小眼睛/观看数，无法完整判断点击与流量质量。
```

```
