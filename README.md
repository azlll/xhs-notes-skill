# xhs-notes-skill（图文笔记.skill）

`xhs-notes-skill` 是面向小红书/XHS/RedNote 图文内容的 Agent Skill。当前版本按“单功能 + 工作流”组织能力：用户可以只查热点、生成标签、分析封面，也可以让 Skill 自动串联选题、写笔记、复盘或拆解。

> 模型要求：图片分析需要支持图片输入的多模态模型。纯文本模型只能基于用户描述处理。

## 默认拷问规则

Skill 默认会先做温和顾问式拷问，把主题、目标人群、内容目标、素材和禁区问清楚。每轮最多问 3 个问题，优先用选项框；如果当前客户端没有选项框，就用简短文本选项。

用户明确说“不要问”“直接生成”“你自己决定”时，Skill 会用合理默认值继续，例如“新手友好 + 收藏导向 + 真实分享”。

选题必须先有大方向。用户只说“帮我选题”但没有主题、赛道、账号方向、产品、素材或目标人群时，Skill 会先问方向，不会直接发散建议。

单功能不越界：用户要标签就只给标签，用户要热点就只查热点，用户要写笔记才进入完整写笔记工作流。

## 默认联网查询

Skill 默认联网查询热点、热梗、热词和小红书官方活动/话题挑战。推荐搜索平台名称包括：小红书、小红书创作中心、小红书蒲公英、百度、微信搜一搜、微博、抖音、知乎、即刻、B站、头条、Google、Bing。

活动查询只覆盖小红书官方活动、话题挑战、创作活动和官方账号发布的活动信息；普通热点、节日节点、电商节点归入热点查询，不混在活动查询里。

联网结果只作为当次参考，不把未经确认的信息写成事实。联网失败时，会说明未完成联网校验，并用内置知识降级处理。

## 图片分析会看哪些信息

上传图片后，Skill 会区分：

- 可见事实：主体、场景、构图、光线、色彩、文字、水印、品牌或地点线索。
- 合理推断：季节、氛围、适合人群、内容角度。
- 不确定信息：价格、店名、地点、真实体验、人物身份、品牌等需要用户确认的内容。
- 风险点：肖像、版权、功效承诺、绝对化表达、AI 内容标注等。

## 怎样提需求效果更好

推荐输入结构：

```text
主题/图片 + 目标人群 + 内容目标 + 语气风格 + 必须保留/必须避免 + 希望输出的内容
```

例子：

```text
使用 xhs-notes-skill 帮我完整写一篇小红书图文笔记。
主题：通勤包收纳
目标人群：刚上班、包里经常乱的人
目标：提升收藏
风格：真实分享，不要太营销
要求：不要编造品牌和价格；输出封面建议、标题、正文、标签、评论钩子和风险检查。
```

## 复盘说明

复盘笔记必须提供单篇笔记链接。如果没有链接，Skill 会先要求补充链接，不直接复盘。链接不可访问或公开字段不足时，可以再补充截图、标题、正文、标签和数据。

复盘重点包括：

- 数据结论
- 流量漏斗
- 封面标题点击诊断
- 目标人群与关键词匹配
- 当前补救动作
- 下一篇实验卡
- 数据缺口和弱判断说明

## 纯文本降级

如果 Python 不可用、脚本缺失或本地输出目录不可写，Skill 不把任务当作整体失败。复盘看板类请求会输出 `发布后复盘报告（Markdown 降级版）`，用 Markdown 表格替代图表，并说明未生成真实 HTML。

## 未来规划

以下能力不在当前版本中实现，仅作为后续升级方向：

1. 博主主页分析 / 蒸馏博主：分析博主主页内容结构、选题规律、封面标题风格和可学习模板。
2. 视频方向：探索短视频脚本、分镜、口播稿、视频封面和视频复盘能力。
3. IP 生成：帮助用户规划账号定位、人设表达、栏目设计和长期内容地图。
4. 找对标账号：按赛道、人群和内容形态寻找可参考账号，并输出学习建议。
5. 封面生图和封面编辑器：后续版本再完善封面图片生成、封面编辑器和本地导出流程。

## 注意事项

- 不保证内容一定爆款，Skill 的目标是提升创作效率和内容完整度。
- 医疗、金融、功效、投资、减肥等高风险内容必须使用审慎表达。
- 不编造真实体验、地点、价格、品牌功效、活动资格和数据。
- 发布反馈截图需打码昵称、头像、私信、订单、联系方式和后台敏感数据。
- 不要把 `config/image_model.json` 或任何真实 API Key 提交到版本库。
