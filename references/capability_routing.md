# 能力路由规则

## 目标

让 Agent 先判断用户要的是使用说明、单功能、工作流、复盘、拆解还是继续修改。路由必须降低用户使用门槛，同时避免单功能输出越界。

## 触发别名

以下说法都视为调用 `xhs-notes-skill`，不要求用户重新输入标准名称：

- 小红书图文笔记skill
- 图文skill
- 笔记skill
- 小红书skill

用户在 `skill` 前后加空格、大小写不同或混用中英文时，也按同一 Skill 处理。

## 使用说明响应

用户问“怎么用”“如何使用”“这个 skill 能做什么”“有哪些功能”“不会用”“作者是谁”“工作量多大”时，只输出使用说明，不进入温和顾问式拷问或任何创作流程。

使用说明必须同时包含：

- 作者信息：版本、作者、小红书主页。
- 工作流和用法：4 个工作流各给 1 条可复制指令。
- 单功能和用法：至少列出 13 个单功能名称；短版可按一行合并示例，完整版逐条给指令。
- 工作量说明：按轻量单功能、中等工作流、重度复盘/拆解说明用户需要准备什么、预计交互轮次。
- 推荐入门用法：告诉用户“不确定就让 Skill 判断该用哪个功能”。

## 短版菜单

用户只问“怎么用”“这个 skill 能做什么”“不会用”时，给短版但完整的菜单：

```text
xhs-notes-skill 可以帮你做小红书图文笔记的选题、写作、分析、复盘和拆解。

作者：程小朱
小红书主页：https://www.xiaohongshu.com/user/profile/5b589d65e8ac2b0abf539cd0

工作流用法：

1. 选题工作流：使用 xhs-notes-skill 帮我从 0 到 1 拷问并规划小红书选题。
2. 写笔记工作流：使用 xhs-notes-skill 帮我完整写一篇小红书图文笔记。
3. 复盘笔记工作流：使用 xhs-notes-skill 帮我复盘这篇已发布的小红书笔记：[粘贴笔记链接]
4. 拆解笔记工作流：使用 xhs-notes-skill 帮我拆解这篇小红书笔记：[粘贴笔记链接]

单功能用法：
使用 xhs-notes-skill 帮我选题 / 判断笔记风格 / 做封面建议 / 查询热点 / 查询热梗 / 查询热词 / 查询活动 / 检查违禁词 / 生成标签 / 生成评论钩子 / 分析封面 / 分析标题 / 分析内容。

工作量：
1. 轻量单功能：适合只要标签、标题分析、违禁词检查等，通常 1 轮输入即可。
2. 中等工作流：适合完整选题或写笔记，需要主题、目标人群、素材和风格，通常 2-4 轮交互。
3. 重度复盘/拆解：适合已发布笔记诊断或拆优质笔记，需要链接、截图、正文或后台数据，可能多轮补充信息。

如果你不确定用哪个功能，直接说：
使用 xhs-notes-skill 帮我判断我现在该用哪个功能。

如果你想看全部功能，回复“完整功能列表”。
```

## 完整功能列表

用户要求“完整功能列表”“详细用法”“所有功能怎么用”时，展示以下内容，并保留作者信息和工作量说明：

作者信息：

- 版本：2.0.0
- 作者：程小朱
- 小红书主页：https://www.xiaohongshu.com/user/profile/5b589d65e8ac2b0abf539cd0

工作流：

1. 选题工作流：使用 xhs-notes-skill 帮我从 0 到 1 拷问并规划小红书选题。
2. 写笔记工作流：使用 xhs-notes-skill 帮我完整写一篇小红书图文笔记。
3. 复盘笔记工作流：使用 xhs-notes-skill 帮我复盘这篇已发布的小红书笔记：[粘贴笔记链接]
4. 拆解笔记工作流：使用 xhs-notes-skill 帮我拆解这篇小红书笔记：[粘贴笔记链接]

单功能：

1. 选题：使用 xhs-notes-skill 帮我拷问并生成一组选题。
2. 笔记风格助手：使用 xhs-notes-skill 帮我判断这篇笔记适合什么风格。
3. 封面制作：使用 xhs-notes-skill 帮我做封面建议、简单模板和生图提示词。
4. 热点查询：使用 xhs-notes-skill 帮我查询这个主题最近能借势的热点。
5. 热梗查询：使用 xhs-notes-skill 帮我查询这个主题适合用的热梗。
6. 热词查询：使用 xhs-notes-skill 帮我查询这个主题相关的小红书热词。
7. 活动查询：使用 xhs-notes-skill 帮我查询小红书里这个主题可参加的官方活动或话题挑战。
8. 违禁词查询：使用 xhs-notes-skill 帮我检查这段文案有没有违禁词或风险表达。
9. 标签生成：使用 xhs-notes-skill 帮我给这篇笔记生成小红书标签。
10. 评论钩子生成：使用 xhs-notes-skill 帮我生成置顶评论和评论区互动钩子。
11. 封面分析：使用 xhs-notes-skill 帮我分析这个封面的美观程度、点击欲和信息表达。
12. 标题分析：使用 xhs-notes-skill 帮我分析这个标题的关键词覆盖和点击欲。
13. 内容分析：使用 xhs-notes-skill 帮我分析这篇内容的关键词覆盖和目标人群。

工作量：

1. 轻量单功能：用户只需提供标题、正文、图片描述、主题或数据中的一种；Agent 应只执行对应功能，通常 1 轮输出。
2. 中等工作流：用户需要提供主题/赛道、目标人群、素材、内容目标、风格偏好；Agent 可先拷问再产出，通常 2-4 轮。
3. 重度复盘/拆解：用户需要提供单篇笔记链接，最好补充截图、正文、标签和后台数据；Agent 可能先追问关键缺口，再给诊断或拆解。

## 意图路由

- 用户只说“怎么用”：输出短版菜单，不进入拷问。
- 用户点名单功能：只执行单功能，缺上下文时先做温和顾问式拷问。
- 用户要求完整产出一篇笔记：进入写笔记工作流。
- 用户要求“复盘”：先检查是否有单篇笔记链接；无链接先反问。
- 用户要求“拆解”：优先要求链接，也可接受截图或完整内容。
- 用户继续修改上一轮结果：沿用已知上下文，不重新给菜单。

## 默认温和顾问式拷问

除非用户明确说“不要问”“直接生成”“你自己决定”，否则执行创作、分析或工作流前，先用温和顾问式拷问补齐关键上下文。每轮最多 3 个问题，问题必须会影响输出。

常用问题：

```text
我先帮你把方向定准，回答编号即可：

1. 这篇主要想吸引谁？
A. 新手小白
B. 有经验但想省时间的人
C. 准备购买/决策的人
D. 其他：你补充

2. 看完后你希望他做什么？
A. 收藏
B. 评论
C. 私信/咨询
D. 关注

3. 有什么必须保留或不能写？
```

## 单功能不越界

- 用户要标签生成，只输出标签建议、标签分层和使用建议。
- 用户要热点查询，只输出热点结果、适配角度和风险，不写完整笔记。
- 用户要封面分析，只分析封面，不默认生成新封面。
- 用户要违禁词查询，只做风险标注和安全改写，不进入选题或写笔记。

## 未来能力边界

当前版本不执行以下能力：博主主页分析 / 蒸馏博主、视频脚本或视频复盘、IP 生成、找对标账号、封面生图和封面编辑器。用户询问时，说明属于未来规划，并可建议使用当前的选题、拆解、封面制作建议或写笔记工作流替代。
