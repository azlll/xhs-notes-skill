# 发布后复盘规则

## 目标

帮助 Agent 基于用户提供的单篇小红书笔记链接、公开可见信息和用户补充数据，完成数据诊断、封面标题点击诊断、内容分析、当前补救动作和下一篇实验建议。复盘只做“可能原因”和“验证假设”，不承诺爆款。

## 入口条件

复盘笔记必须提供单篇笔记链接。硬性规则：必须提供笔记链接。没有链接时无链接先反问，不直接复盘：

```text
可以。请先把要复盘的小红书笔记链接发我。

如果你有后台数据，也可以一起贴上：
曝光、小眼睛/观看、点赞、收藏、评论、分享、关注/私信/转化。
```

链接不可访问、遇到验证码、权限限制、字段不可见或平台限制时，停止抓取，并提示用户补充截图、标题、正文、标签和数据。

## 输入结构

必须：

- 单篇链接：小红书笔记链接。

推荐：

- 笔记目标：提升收藏、评论、关注、咨询或成交。
- 数据：曝光、小眼睛/观看/阅读/查看数、点赞、收藏、评论、分享、关注、私信、转化。
- 截图：封面、笔记页、数据页；截图需打码昵称、头像、私信、订单、联系方式和后台敏感信息。

## 抓取边界

- 只使用公开可见信息。
- 不登录、不绕过验证码、不破解接口。
- 不采集私信、订单或后台数据。
- 不把公开互动数反推成观看数或曝光。

## 复盘前整理

优先整理成以下结构；缺失字段保留为空，不要编造：

```json
{
  "note": {
    "title": "笔记标题",
    "body": "正文",
    "tags": ["标签1", "标签2"],
    "published_at": "发布时间",
    "goal": "笔记目标",
    "link": "单篇链接",
    "images": ["本地图片路径或截图路径"]
  },
  "metrics": {
    "exposure": 0,
    "views": 0,
    "likes": 0,
    "favorites": 0,
    "comments": 0,
    "shares": 0,
    "follows": 0,
    "conversions": 0
  }
}
```

## 必要数据追问

- 小眼睛/观看数必问：`metrics.views` 对应小红书公开或后台里的小眼睛、观看、阅读、查看数；它不等同于曝光。
- `metrics.exposure` 只表示曝光/展现；有曝光和观看时，才可判断点击效率或入口转化。
- 单篇链接抓不到 `views` 时，先问用户：`我没有拿到小眼睛/观看数，这会影响流量判断。请补充观看数，或回复“跳过”继续做不完整复盘。`
- 用户补充 views 后再输出完整报告；用户明确回复“跳过”后，报告必须标注“不完整流量诊断：缺少小眼睛/观看数，无法完整判断点击与流量质量”。

## 流量漏斗诊断

按链路逐项判断：

- 曝光：选题、账号基础、发布时间、标签和平台分发可能影响初始触达；缺曝光时不计算点击率。
- 观看/小眼睛：封面、标题、首图信息密度、搜索关键词和人群匹配可能影响点击；缺 views 时先追问或标注不完整流量诊断。
- 点赞：情绪共鸣、观点表达、审美和即时认同可能影响点赞。
- 收藏：清单、步骤、参数、避坑、模板和复用价值可能影响收藏。
- 评论：问题设计、争议边界、经验征集和置顶评论可能影响讨论。
- 分享：信息密度、社交货币、实用清单和情绪表达可能影响转发。
- 关注/转化：账号人设、系列感、信任证据、行动路径和商品/服务承接可能影响后续动作。

## 封面标题点击诊断

- 结合封面/首图、标题、首图文字、目标人群和 `views`/`exposure` 判断入口吸引力。
- 判断标题是否包含赛道词、人群词、问题词或长尾搜索词。
- 判断封面是否能在 1 秒内让目标人群看懂“这篇和我有关吗”。
- 输出保留点、问题点、当前可补救动作和下一篇实验。

## 目标人群与关键词匹配

复盘时默认联网搜索同类笔记/赛道的目标人群、搜索关键词、热门标签和常见标题表达，用于判断：

- 这篇笔记更像推荐流量内容还是搜索流量内容。
- 目标人群是否明确。
- 封面标题是否能让这群人自我识别。
- 当前标签和正文关键词是否覆盖赛道词、人群词、痛点词、内容形态词和长尾搜索词。

联网不可用或结果不可靠时，说明“未完成联网关键词校验”，并用现有标题、标签和正文做弱判断。

## 附录参考评分

六维评分保留但弱化，不放在主结论，不生成主导性的总分。

固定维度：

1. 入口吸引力：封面/首图、标题钩子、场景识别度和点击动机。
2. 标题搜索力：关键词、赛道词、场景词、长尾搜索价值和表达清晰度。
3. 正文承接力：开头钩子、中段信息、真实感、节奏和读完动力。
4. 收藏价值：清单化、步骤化、参数化、避坑点和复用价值。
5. 评论互动：置顶评论、引导问题、讨论空间和回复延展性。
6. 转化/关注潜力：账号人设、系列感、信任证据、行动路径和关注理由。

## HTML 降级边界

HTML 看板不是新版默认入口。用户明确要求网页、HTML、看板或可视化报告时，可继续使用现有报告脚本；脚本不可用时按 [脚本降级输出规则](fallback_outputs.md) 输出 `发布后复盘报告（Markdown 降级版）`。

可选 HTML 报告里可以继续把六维雷达图、指标柱状图、互动占比饼图和连线图放在附录或可视化区域，但这些图表不作为新版复盘工作流的默认主结论。
