# 发布后复盘规则

## 目标

帮助 Agent 基于用户提供的已发布小红书笔记内容和可见数据，完成全链路诊断、六维评分、下一篇实验建议，并在需要时生成本地 HTML 可视化复盘看板。复盘只做“可能原因”和“验证假设”，不承诺爆款，不把平台算法写成确定结论。

## 触发输入

支持且只支持以下数据入口：

- 手动数据：用户粘贴标题、正文、标签、发布时间、曝光、阅读/点击、点赞、收藏、评论、分享、关注、转化等。
- 截图识别：用户上传笔记页面、创作中心或数据截图；先提醒打码昵称、头像、私信、订单、联系方式和后台敏感信息。
- 单篇链接：抓取公开可见的笔记标题、正文、标签、封面/图片、发布时间和可见互动数。
- 主页链接：抓取公开可见的主页信息和当前可加载的公开笔记，用于账号内容结构与近期表现复盘。

链接抓取边界：

- 只使用公开可见信息。
- 不登录、不绕过验证码、不破解接口、不采集私信、订单或后台数据。
- 遇到验证码、权限限制、加载失败、字段不可见或平台限制时停止抓取，并友好提示用户提供截图或文字信息。

## 全链路诊断

按链路逐项判断：

- 曝光：选题、账号基础、发布时间、标签和平台分发可能影响初始触达。
- 阅读/点击：封面、标题、首图信息密度、搜索关键词和人群匹配可能影响点击。
- 点赞：情绪共鸣、观点表达、审美和即时认同可能影响点赞。
- 收藏：清单、步骤、参数、避坑、模板和复用价值可能影响收藏。
- 评论：问题设计、争议边界、经验征集和置顶评论可能影响讨论。
- 分享：信息密度、社交货币、实用清单和情绪表达可能影响转发。
- 关注/转化：账号人设、系列感、信任证据、行动路径和商品/服务承接可能影响后续动作。

数据缺失时：

- 不计算不可见的点击率、转化率或后台指标。
- 可用“无法判断，需要补充曝光/阅读/关注等数据”说明缺口。
- 不把单篇链接公开互动数当作完整后台表现。

## 六维评分

固定维度：

1. 入口吸引力：封面/首图、标题钩子、场景识别度和点击动机。
2. 标题搜索力：关键词、赛道词、场景词、长尾搜索价值和表达清晰度。
3. 正文承接力：开头钩子、中段信息、真实感、节奏和读完动力。
4. 收藏价值：清单化、步骤化、参数化、避坑点和复用价值。
5. 评论互动：置顶评论、引导问题、讨论空间和回复延展性。
6. 转化/关注潜力：账号人设、系列感、信任证据、行动路径和关注理由。

每项输出：

- `score`：0-100；数据不足时可为空或标注为“数据不足”。
- `evidence`：来自标题、正文、图片、标签或数据的具体依据。
- `confidence`：高/中/低；公开链接数据或截图缺字段时通常为中或低。

总分按已有六维分数平均；若有维度缺失，说明“部分维度数据不足，总分仅供参考”。

## HTML 看板

用户要求“生成网页/HTML/看板/可视化报告”时：

1. 先完成复盘判断，再整理 JSON。
2. 调用 `python3 scripts/generate_review_report.py --input <review.json> --output-dir outputs/reports`。
3. 返回生成的本地 HTML 路径。

HTML 看板必须包含：

- 用户输入的图片、标题、正文、标签、链接和发布时间。
- 总分和六维评分。
- 六维雷达图、指标柱状图、互动占比饼图和连线图。
- 全链路诊断、主要问题排序、原因假设、风险边界。
- 下一篇实验卡：假设、改法、成功指标和执行建议。

下一篇建议必须落到可执行项，至少覆盖封面、标题、开头、正文结构、标签、评论钩子、发布时间或选题方向中的 3 项。

## 输出文本模板

生成 HTML 后，在对话中简短说明：

```markdown
已生成发布后复盘 HTML 看板：
- 文件：[outputs/reports/xxx.html]
- 包含：总分、六维雷达图、柱状图、饼图、连线图、全链路诊断和下一篇实验卡
- 提醒：本次复盘只基于已提供/公开可见数据，缺失字段未做推断
```

如果无法生成 HTML，说明缺少的字段或失败原因，并引导用户补充截图或文字信息。
