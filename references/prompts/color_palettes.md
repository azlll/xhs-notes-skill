# 配色方案库

## 使用原则

- 每组图片保持主色一致，避免一篇笔记颜色跳跃太大。
- 封面用对比更清晰的主色；内页可以降低饱和度。
- 文字区域背景要干净，避免高纹理和强反光。

## 美食类

### 暖白 + 番茄红 + 木色

- 适合：家常菜、早餐、面食。
- 氛围：温暖、可口、真实。
- Prompt 片段：`暖白背景，番茄红点缀，浅木色餐桌`

### 奶油黄 + 抹茶绿 + 米白

- 适合：甜品、轻食、早餐。
- 氛围：清新、柔和、治愈。
- Prompt 片段：`奶油黄和抹茶绿配色，低饱和，明亮自然光`

## 穿搭类

### 黑白灰 + 牛仔蓝

- 适合：通勤、基础款、一衣多穿。
- 氛围：利落、耐看、实穿。
- Prompt 片段：`黑白灰主色，牛仔蓝点缀，城市通勤感`

### 燕麦色 + 焦糖棕 + 暖白

- 适合：秋冬穿搭、温柔风、质感穿搭。
- 氛围：温暖、稳定、有质感。
- Prompt 片段：`燕麦色大衣，焦糖棕配饰，暖白背景`

## 家居类

### 白色 + 浅木色 + 鼠尾草绿

- 适合：小户型、厨房、书桌、收纳。
- 氛围：清爽、自然、不压空间。
- Prompt 片段：`白色和浅木色为主，鼠尾草绿小面积点缀`

### 雾蓝 + 暖灰 + 银色

- 适合：浴室、清洁工具、现代家居。
- 氛围：干净、冷静、有秩序。
- Prompt 片段：`雾蓝和暖灰配色，银色金属细节`

## 知识卡片类

### 深墨绿 + 米白 + 浅金

- 适合：方法论、阅读、效率、学习。
- 氛围：稳重、专业、可收藏。
- Prompt 片段：`深墨绿标题区，米白卡片背景，浅金细线分隔`

### 珊瑚橙 + 浅蓝 + 白色

- 适合：轻科普、生活技巧、新手指南。
- 氛围：活泼、清晰、友好。
- Prompt 片段：`珊瑚橙重点色，浅蓝辅助色，白色留白`

## 生活方式类

### 奶油白 + 浅粉 + 橄榄绿

- 适合：周末、独处、手账、轻运动。
- 氛围：柔和、放松、亲近。
- Prompt 片段：`奶油白背景，浅粉和橄榄绿点缀`

### 胶片黄 + 暖棕 + 暗红

- 适合：旅行、咖啡店、复古街景。
- 氛围：怀旧、松弛、有故事感。
- Prompt 片段：`胶片黄高光，暖棕阴影，暗红小面积点缀`
