# 正文模板

## 通用结构

```text
开头钩子：一句话说痛点、结果或反差。
背景说明：为什么写这篇，适合谁。
核心内容：步骤、清单、对比、经验或方法。
真实感补充：成本、时间、难度、适用边界。
结尾互动：引导收藏、评论、补充需求。
```

## STAR 结构模板

适合经验复盘、改造、成长、好物使用场景。

- Situation：当前场景和问题。
- Task：要解决的目标。
- Action：具体做了什么。
- Result：带来什么变化，使用审慎表达。

模板：

```text
之前我在[场景]一直遇到[问题]。
这次目标很简单：想让[结果]更[具体感受]。
我主要做了3件事：
1. [动作一]，原因是[逻辑]。
2. [动作二]，注意[细节]。
3. [动作三]，适合[边界]。
调整后，[结果变化]。不一定适合所有人，但如果你也有[相同痛点]，可以先从[最低成本动作]试试。
```

## 教程型模板

适合美食、手作、软件、拍照、收纳。

```text
[结果]其实不难，容易翻车的地方通常在[关键点]。

材料/工具：
- [材料1]
- [材料2]
- [可替代项]

步骤：
1. [步骤一]：注意[细节]。
2. [步骤二]：判断标准是[状态]。
3. [步骤三]：如果[异常情况]，可以[补救]。

我的小经验：
- [经验1]
- [经验2]

适合[人群/场景]，建议先收藏，做的时候对照看。
```

## 清单型模板

适合知识卡片、购物清单、旅行准备、收纳方案。

```text
我把[主题]整理成了一份清单，适合[人群/场景]直接对照。

✅ [清单项1]：解决[问题]。
✅ [清单项2]：注意[条件]。
✅ [清单项3]：更适合[边界]。

不建议：
- [误区1]
- [误区2]

如果你也在准备[场景]，可以先收藏这份清单。
```

## 种草型模板

适合好物、穿搭、家居、护肤以外的低风险商品分享。

```text
最近在[场景]用到/穿到[对象]，比我想象中更适合[具体需求]。

我喜欢的点：
1. [卖点一]，对应[使用场景]。
2. [卖点二]，对[人群]比较友好。
3. [卖点三]，但要注意[边界/缺点]。

不适合：
- [不适合人群]
- [不适合场景]

总体更推荐给[明确人群]。如果你也在找[需求]，可以拿这个标准去对比。
```

## 避坑型模板

适合购买决策、教程翻车、装修收纳、穿搭误区。

```text
这次踩坑后发现，[问题]不是因为[表面原因]，而是[真实原因]。

我踩过的坑：
1. [坑一]：表现是[现象]，解决方式是[方法]。
2. [坑二]：不要只看[单一指标]，还要看[关键指标]。
3. [坑三]：如果你是[人群]，建议[替代做法]。

下次我会这样选：
- [标准1]
- [标准2]
- [标准3]

希望你不用再踩同样的坑。
```

## 对比型模板

适合前后对比、单品对比、方案对比。

```text
同样是[对象]，换成[方案B]之后，差别主要在这几处：

对比1：[维度]
- A：[表现]
- B：[表现]

对比2：[维度]
- A：[表现]
- B：[表现]

我的选择建议：
- 如果你更在意[需求]，选[方案]。
- 如果你预算/空间/时间有限，先选[方案]。
```

## 口吻规则

- 少用空泛形容词，多写可感知细节。
- 每段尽量 1-3 行，适合手机阅读。
- 使用“我更建议”“可以先试试”“更适合”替代强制命令。
- 对产品、功效、收益类内容写明适用边界。
