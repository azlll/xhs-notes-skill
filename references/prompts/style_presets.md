# 风格预设

## 真实生活摄影

适合美食、家居、穿搭、生活方式。

Prompt 片段：

- `真实生活摄影风格`
- `自然光，轻微胶片颗粒`
- `不过度商业棚拍，保留生活感`

## 极简干净风

适合知识卡片、好物、收纳、封面。

Prompt 片段：

- `极简构图，留白充足`
- `干净背景，低饱和配色`
- `主体清晰，适合叠加中文标题`

## 手绘插画风

适合知识科普、清单、生活方式。

Prompt 片段：

- `温和手绘插画风`
- `细线条，柔和色块`
- `轻量纸张纹理，画面亲切`

## 卡通风

适合轻松科普、儿童相关但非敏感内容、生活小技巧。

Prompt 片段：

- `简洁卡通插画`
- `圆润造型，明快色彩`
- `可爱但不过度幼稚`

## 胶片感

适合穿搭、旅行、咖啡店、周末生活。

Prompt 片段：

- `35mm film photography`
- `柔和自然光，轻微颗粒`
- `低对比，温暖高光`

## 杂志编辑风

适合穿搭、产品、生活方式封面。

Prompt 片段：

- `杂志编辑风构图`
- `主体姿态自然，背景有层次`
- `高级但不夸张，适合小红书封面`

## 产品平铺风

适合好物清单、收纳工具、彩妆以外低风险产品。

Prompt 片段：

- `flat lay product photography`
- `物品整齐排列，间距统一`
- `俯拍，清晰展示每个单品`

## 家居温暖风

适合家居、收纳、租房改造。

Prompt 片段：

- `温暖居家氛围`
- `柔和台灯和自然光混合`
- `空间干净但有真实生活痕迹`

## 街拍通勤风

适合穿搭分享。

Prompt 片段：

- `城市街拍，通勤场景`
- `人物全身构图，姿态自然`
- `背景轻微虚化，突出服装轮廓`

## 知识卡片风

适合方法论、速查表、清单。

Prompt 片段：

- `知识卡片视觉`
- `分区清晰，图标辅助说明`
- `不生成具体文字，预留中文排版区域`
