# 主题确认与选题规则

## 目标

选题必须先有大方向，再根据用户目标、人群、素材和趋势生成可执行选题。没有方向时不要像无头苍蝇一样发散。

## 大方向优先

如果用户没有提供主题、赛道、账号方向、产品、素材或目标人群，不得直接生成选题，先反问；也就是没有主题时先定方向：

```text
我先不直接给选题，否则会太散。先定一个大方向，回答编号即可：

1. 你更想做哪个方向？
A. 生活方式/日常
B. 好物种草
C. 职场/学习
D. 美食/探店
E. 穿搭/美妆
F. 旅游/本地生活
G. 知识/IP/个人经验
H. 其他：你补充
```

如果用户仍然不知道，再问账号目标：

```text
那我先问一个更简单的：你更想用这个账号实现什么？
A. 记录生活
B. 涨粉
C. 引流获客
D. 卖产品/服务
E. 练习内容能力
```

## 温和顾问式拷问

用户给出大方向后，再问目标人群、内容目标、可用素材和内容边界。每轮最多 3 个问题。

示例：

```text
我先帮你把选题范围收窄，回答编号即可：

1. 这次更想写哪类内容？
A. 干货教程
B. 真实经验
C. 好物种草
D. 避坑清单

2. 目标人群是谁？
A. 新手
B. 有经验但想省时间的人
C. 正在决策/购买的人
D. 其他：你补充

3. 你手上有什么素材？
A. 图片/视频
B. 真实经历
C. 产品/案例
D. 还没有
```

## 选题建议

生成 5-8 个选题，每个选题包含：

- 选题名：一句话概括发布角度。
- 适合人群：谁会被这篇笔记吸引。
- 内容角度：从什么切口写。
- 推荐风格：真实分享、干货清单、种草、避坑、教程、探店、情绪共鸣等。
- 封面方向：封面文字或画面结构建议。
- 为什么值得写：点击、收藏、评论或共鸣的原因。
- 需要素材：图片、经历、产品、案例或数据。
- 注意事项：不能编造或需要审慎表达的信息。

```markdown

- 内容角度：
- 推荐风格：
- 封面方向：

- 需要素材：
- 注意事项：

## 优先推荐

我建议先做：
1. [选题名]：理由
2. [选题名]：理由

## 趋势参考

- 热点：
- 热梗：
- 热词：
- 未采用的信息：

## 下一步

如果要继续，可以说：
使用 xhs-notes-skill 帮我把第 X 个选题写成完整笔记。
```

## 联网关系

- 默认联网查询热点、热梗、热词。
- 只采用与大方向、目标人群和用户素材强相关的信息。
- 不为了蹭热点扩大到无关新闻或泛娱乐热点。
- 查不到可靠趋势时，说明未完成联网校验，用内置经验生成。
