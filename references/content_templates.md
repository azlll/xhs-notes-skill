# 正文模板

## 通用结构

```text
开头钩子：一句话说痛点、结果或反差。
背景说明：为什么写这篇，适合谁。
核心内容：步骤、清单、对比、经验或方法。
真实感补充：成本、时间、难度、适用边界。
结尾互动：引导收藏、评论、补充需求。
```

## STAR 结构模板

适合经验复盘、改造、成长、好物使用场景。

- Situation：当前场景和问题。
- Task：要解决的目标。
- Action：具体做了什么。
- Result：带来什么变化，使用审慎表达。

模板：

```text
之前我在[场景]一直遇到[问题]。
这次目标很简单：想让[结果]更[具体感受]。
我主要做了3件事：
1. [动作一]，原因是[逻辑]。
2. [动作二]，注意[细节]。
3. [动作三]，适合[边界]。
调整后，[结果变化]。不一定适合所有人，但如果你也有[相同痛点]，可以先从[最低成本动作]试试。
```

## 教程型模板

适合美食、手作、软件、拍照、收纳。

```text
[结果]其实不难，容易翻车的地方通常在[关键点]。

材料/工具：
- [材料1]
- [材料2]
- [可替代项]

步骤：
1. [步骤一]：注意[细节]。
2. [步骤二]：判断标准是[状态]。
3. [步骤三]：如果[异常情况]，可以[补救]。

我的小经验：
- [经验1]
- [经验2]

适合[人群/场景]，建议先收藏，做的时候对照看。
```

## 清单型模板

适合知识卡片、购物清单、旅行准备、收纳方案。

```text
我把[主题]整理成了一份清单，适合[人群/场景]直接对照。

✅ [清单项1]：解决[问题]。
✅ [清单项2]：注意[条件]。
✅ [清单项3]：更适合[边界]。

不建议：
- [误区1]
- [误区2]

如果你也在准备[场景]，可以先收藏这份清单。
```

## 种草型模板

适合好物、穿搭、家居、护肤以外的低风险商品分享。

```text
最近在[场景]用到/穿到[对象]，比我想象中更适合[具体需求]。

我喜欢的点：
1. [卖点一]，对应[使用场景]。
2. [卖点二]，对[人群]比较友好。
3. [卖点三]，但要注意[边界/缺点]。

不适合：
- [不适合人群]
- [不适合场景]

总体更推荐给[明确人群]。如果你也在找[需求]，可以拿这个标准去对比。
```

## 避坑型模板

适合购买决策、教程翻车、装修收纳、穿搭误区。

```text
这次踩坑后发现，[问题]不是因为[表面原因]，而是[真实原因]。

我踩过的坑：
1. [坑一]：表现是[现象]，解决方式是[方法]。
2. [坑二]：不要只看[单一指标]，还要看[关键指标]。
3. [坑三]：如果你是[人群]，建议[替代做法]。

下次我会这样选：
- [标准1]
- [标准2]
- [标准3]

希望你不用再踩同样的坑。
```

## 对比型模板

适合前后对比、单品对比、方案对比。

```text
同样是[对象]，换成[方案B]之后，差别主要在这几处：

对比1：[维度]
- A：[表现]
- B：[表现]

对比2：[维度]
- A：[表现]
- B：[表现]

我的选择建议：
- 如果你更在意[需求]，选[方案]。
- 如果你预算/空间/时间有限，先选[方案]。
```

## 探店推荐模板

适合路边摊、咖啡店、餐厅、夜市、本地生活。

```text
在[地点/街区]路过[店/摊/空间]，没想到[第一感受]。

我点/看到的是[对象]：
- [细节1]：比如[可见口感/氛围/服务细节]。
- [细节2]：更适合[人群/场景]。
- [细节3]：需要注意[口味/排队/时间/边界]。

最打动我的是[氛围/烟火气/真实感]。

适合：
- [人群1]
- [场景1]

不确定信息：
- 价格、地址、营业时间请以现场/官方信息为准。

如果你也在[城市/街区]附近，可以路过时试试。
```

## 情绪鸡汤模板

适合风景图、城市黄昏、独处、低谷自愈、生活方式。

```text
看到这张图的时候，我突然想到[情绪/状态]。

[画面事实]其实很普通，但它给人的感觉是[情绪价值]。

也许我们不需要每一天都[高要求]。
有时候，只要[低门槛动作]，就已经是在往前走。

如果你最近也[状态]，先允许自己[温和行动]。

日子不会因为一句话立刻变好，但你可以先从[具体小事]开始。
```

## 热点借势模板

适合节日、节点、平台热词、社会热点的轻借势。只在热点可验证时使用。

```text
最近[节点/热点]很有讨论感，但我更想从[个人角度]聊聊。

这件事放到[用户场景]里，其实对应的是[痛点/需求]。

可以先做3个小调整：
1. [动作1]
2. [动作2]
3. [动作3]

不需要硬蹭热点，重点是让内容和[用户真实需求]有关。
```

## 产品测评模板

适合好物、工具、家居用品、低风险消费品。

```text
我按[使用场景]试了[对象]，这篇只写真实感受。

优点：
1. [优点1]：适合[场景]。
2. [优点2]：对[人群]比较友好。

缺点/边界：
1. [缺点1]
2. [不适合人群]

我的判断：
- 如果你更在意[需求]，可以考虑。
- 如果你更在意[需求]，建议再对比。

不写绝对推荐，按自己的使用场景选。
```

## 图片解读模板

适合用户只给图片，希望图生文。

```text

我看到的画面：
- [可见事实1]
- [可见事实2]
- [可见事实3]

它可以延展成[笔记角度]：
1. [角度1]
2. [角度2]
3. [角度3]

如果要发小红书，我会用[语气]写，让读者先被画面吸引，再进入[正文价值]。
```

## 节日节点模板

适合春节、元宵、清明、五一、端午、七夕、中秋、国庆、双11、618、开学季、毕业季。

```text
[节点]快到了，我整理了一个适合[人群/场景]的小方案。

这次重点不是[常见误区]，而是[核心价值]。

可以这样安排：
1. [动作1]：适合[场景]。
2. [动作2]：注意[边界]。
3. [动作3]：如果时间有限，先做这个。

适合收藏，到[节点]前后直接对照。
```

## 学习职场模板

适合复盘、效率、打工人、学习方法、工具使用。

```text
[任务]做起来累，很多时候不是能力问题，而是流程不清楚。

我会拆成这几步：
1. [步骤1]：先确定[目标]。
2. [步骤2]：用[工具/模板]减少重复劳动。
3. [步骤3]：最后检查[风险/遗漏]。

适合[人群]先照着做一版，不需要一开始就完美。
```

## 旅行攻略模板

适合城市漫游、周末路线、第一次去某地、短途旅行。

```text
如果你第一次去[城市/地点]，我会建议先按[时间/区域]安排。

路线：
1. [地点1]：适合[理由]。
2. [地点2]：建议[时间/方式]。
3. [地点3]：如果体力够再去。

注意：
- [交通/排队/天气/预约]
- [不适合场景]

这条路线更适合[人群]，不追求打卡数量，适合慢慢逛。
```

## AI 创作拆解模板

适合 AI 绘画、Prompt 分享、封面设计、风格二创。

```text
这张 AI 图有记忆点，主要不是因为[表面元素]，而是[反差/风格/构图]。

可以拆成4层：
1. 主体：[主体特点]
2. 风格：[风格关键词]
3. 构图：[构图方式]
4. 情绪：[读者第一感受]

如果要复刻，Prompt 可以围绕[主体 + 风格 + 场景 + 留白 + 负面约束]来写。

发布时注意标注 AI 辅助生成，避免被误认为真实拍摄或原创实物。
```

## 口吻规则

- 少用空泛形容词，多写可感知细节。
- 每段尽量 1-3 行，适合手机阅读。
- 使用“我更建议”“可以先试试”“更适合”替代强制命令。
- 对产品、功效、收益类内容写明适用边界。
