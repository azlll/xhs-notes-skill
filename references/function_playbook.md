# 功能工作流手册

## 输出总原则

- 单功能输出要轻，默认结构为 `## 结果`、`## 判断`、`## 可直接使用`。
- 工作流输出要完整，但围绕用户目标收敛。
- 默认联网查询热点、热梗、热词和活动；查不到可靠信息时说明未完成联网校验，并用内置知识降级。
- 查询结果只作为当次创作参考，不把未经确认的信息写成事实。

## 单功能

### 选题

先确认大方向，再生成 5-8 个选题。没有主题、赛道、账号方向、产品、素材或人群时，不直接发散选题，先反问。

输出：

```markdown
## 选题建议

1. [选题名]
- 适合人群：
- 内容角度：
- 推荐风格：
- 封面方向：
- 为什么值得写：
- 需要素材：
- 注意事项：

## 优先推荐
```

### 笔记风格助手

判断内容适合真实分享、干货清单、种草、避坑、教程、拆解、探店或情绪共鸣。

输出推荐风格、可选风格、开头语气、正文节奏、标题倾向、封面文字倾向和不建议使用的风格。

### 封面制作

只给封面建议、简单模板、封面文案、画面结构和生图 Prompt。当前版本不生成图片、不提示编辑器。

输出：

```markdown
## 封面建议

1. [封面方向名]
- 封面文字：
- 画面结构：
- 适合原因：
- 注意事项：

## 简单模板

## 生图 Prompt
```

### 热点查询

查近期事件、节点、社会讨论和平台趋势。

输出热点名称、适配主题、可借势角度、标题方向和风险。不硬蹭无关社会事件。

### 热梗查询

查网络表达、句式、评论区语言和年轻化表达。

输出热梗/句式、适合用法、适合场景、不适合场景和改写示例。最多推荐 3-5 个。

### 热词查询

查用户可能搜索什么、平台常见怎么叫。

输出核心词、人群词、场景词、痛点词、长尾搜索词、可转成标签的词。热词服务搜索和标签，不等于热梗。

### 活动查询

只查小红书官方活动、话题挑战、创作活动、创作中心活动和官方账号发布的活动信息。

不归入活动查询：节假日、节气、电商大促、微博/抖音/全网热点、普通热门话题、品牌私域招募或无法确认来源的搬运信息。

### 违禁词查询

检查绝对化表达、功效承诺、医疗、金融、投资、玄学、低俗、引战、虚假互动和 AI 内容标注风险，并给安全替换。

### 标签生成

默认生成 8-12 个标签，按赛道词、人群词、场景词、痛点词、长尾词、活动/话题分层。

### 评论钩子生成

输出置顶评论、引导问题和作者回复模板。避免诱导虚假互动、低级争议和敏感私信引导。

### 封面分析

分析美观程度、点击欲、信息表达、平台适配和风险点。没看到图片时，只能基于描述弱分析，不编造图片内容。

### 标题分析

分析关键词覆盖、点击欲、清晰度和风险，并给 3-5 个改写标题。不默认写正文。

### 内容分析

分析目标人群、关键词覆盖、正文承接、收藏价值、评论潜力和风险表达。内容分析不是数据复盘，没有数据时不判断流量表现。

## 工作流

### 选题工作流

大方向确认 → 温和顾问式拷问 → 热点查询 → 热梗查询 → 热词查询 → 笔记风格助手 → 5-8 个选题建议 → 1-2 个优先推荐。

### 写笔记工作流

温和顾问式拷问 → 选题确认或生成 → 热点查询 → 热梗查询 → 热词查询 → 活动查询 → 笔记风格助手 → 标题正文 → 封面制作建议 → 标签生成 → 评论钩子生成 → 违禁词查询 → `## 可复制发布区`。

当前版本写笔记工作流不执行图片生成、不提示封面编辑入口。

### 复盘笔记工作流

必须提供笔记链接 → 整理公开可见信息和用户补充数据 → 流量卡点判断 → 封面分析 → 标题分析 → 内容分析 → 当前补救动作 → 下一篇实验。

如果缺少小眼睛/观看数，先追问；用户回复“跳过”后才输出不完整复盘。

### 拆解笔记工作流

优先使用笔记链接，也可使用截图、标题、正文和标签。拆选题、封面、标题、正文、标签、评论，逐部分讲优点、为什么有效、可复用点，再输出可复用模板和不建议照搬的部分。

拆解不是洗稿。默认不直接改写原文；用户要求同赛道新笔记时，必须基于用户自己的主题、素材和目标人群重新写。
