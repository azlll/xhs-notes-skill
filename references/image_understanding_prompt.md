# 图片理解提示词

## 目标

让 Agent 在图生文前尽可能挖掘图片里的可见信息、可推断信息和时效关系，同时避免把推断写成事实。适用于用户上传 1-10 张图片生成小红书标题、正文、标签、评论钩子、图片排序和发布建议。

## 分析顺序

### 1. 基础视觉事实

逐张图片编号，并记录：

- 主体：人物、食物、产品、风景、建筑、宠物、文字、动作。
- 场景：室内/户外、街边/家中/办公/旅行/餐厅/展览/校园。
- 构图：近景、远景、俯拍、平视、对称、留白、前后景、画面重心。
- 光线：自然光、夜景、逆光、暖光、冷光、阴天、黄昏、强闪光。
- 色彩：主色、辅助色、饱和度、冷暖、季节感。
- 质感：食物口感、衣料、材质、空间整洁度、画面颗粒、AI 生成感。
- 可见文字/OCR：招牌、包装、菜单、价格、标签、水印、时间地点信息。
- 品牌和地点线索：只记录可见或用户提供的信息，不猜品牌、不猜店名。

### 2. 内容潜力

判断图片适合哪些小红书角度：

- 种草：卖点、使用场景、适合人群、注意边界。
- 探店：环境、招牌、食物、排队、价格线索、交通线索。
- 教程：步骤顺序、材料工具、前后对比、可复刻程度。
- 情绪：治愈、松弛、孤独、热闹、烟火气、反差、抽象感。
- 知识：能否拆成清单、方法、避坑、对比、图解。
- 热梗：是否适合“被硬控”“抽象但合理”“活人感”“情绪价值”等轻热词。

### 3. 时效关系

先获取或确认当前信息：

- 当前公历日期、星期、月份、季节。
- 当前农历日期、节气、传统节日。
- 当前法定节假日、调休、开学/毕业/考试/购物节/年末年初等节点。
- 近期社会热点、城市活动、影视综艺、AI 工具热点、平台流行话题。

将图片与时效信息建立关系：

- 季节关系：穿搭、天气、色彩、食物、旅行目的地是否符合当前季节。
- 节日关系：是否适合春节、元宵、清明、五一、端午、七夕、中秋、国庆、双11、618 等节点。
- 平台节点：是否适合开学季、毕业季、年终总结、年度复盘、春日上新、夏日多巴胺、秋冬美拉德。
- 热点关系：图片主题是否能安全借势近期热点；不能确认则只写“可借势方向”，不写具体热点。

### 4. 事实分层

输出分析时必须区分：

- 可见事实：图片中能直接看到的信息。
- 合理推断：基于画面可推断但不确定的信息。
- 不确定信息：需要用户确认的信息，如价格、品牌、地点、真实体验、人物身份。

不要把“可能是”“看起来像”“适合写成”改写成事实。

### 5. 风险点

检查：

- 人脸、车牌、地址、订单号、联系方式、聊天记录是否需要打码。
- 是否存在品牌、版权、商标、名画二创、AI 水印。
- 是否有医疗、金融、功效、减肥、未成年人、食品安全等高风险内容。
- 是否需要 AI 生成标注。
- 是否有夸大体验或无法证明的探店信息。

## 分析输出模板

```markdown
### 图片分析
- 可见事实：
- 合理推断：
- 不确定信息：
- 时效关系：
- 可写角度：
- 风险点：
- 补图建议：
```

## 生成文案前的判断

- 图片信息足够：直接生成可复制发布区。
- 图片信息不足：生成文案时保留可替换字段，并在分析说明提醒用户补充。
- 图片与热点关系不确定：不写具体热点，只写“可结合近期节点/热点做轻借势”。
- 图片有隐私或版权风险：先在风险检查中提醒处理，再生成稳妥文案。
