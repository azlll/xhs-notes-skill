# 构图技巧库

## Prompt 基础结构

```text
[主体]，[场景]，[构图]，[镜头/视角]，[光线]，[风格]，[配色]，[文字区域要求]，[画质要求]，[负面约束]
```

示例：

```text
一碗番茄鸡蛋面放在浅色木质餐桌上，45度俯拍，碗边有筷子和小碟，清晨自然光，真实生活摄影，暖白和番茄红配色，画面上方留出干净标题区，高清细节，不要手部畸形，不要乱码文字
```

## 封面构图

- 主体占画面 45%-65%，不要太小。
- 标题区域预留在上方或左侧，背景尽量干净。
- 使用强识别元素：成品、搭配全身、收纳前后、核心卡片。
- 封面要“一眼知道内容”，不要只做氛围图。

Prompt 片段：

- `主体居中偏下，上方留出大面积干净标题区`
- `前景清晰，背景轻微虚化`
- `小红书封面比例，适合叠加中文标题`

## 步骤图构图

- 每张图只表达一个步骤。
- 加入手部操作可以增强真实感，但要提示手部自然。
- 保持同一背景、同一光线，形成系列感。

Prompt 片段：

- `步骤演示图，单一动作，画面简洁`
- `手部自然，不要多余手指`
- `同一厨房台面，同一自然光`

## 细节图构图

- 用于展示材质、口感、纹理、收纳分区、单品细节。
- 镜头可以更近，但主体边界要清楚。

Prompt 片段：

- `微距细节，突出纹理和质感`
- `浅景深，主体边缘清晰`
- `干净背景，避免杂物`

## 对比图构图

- 适合前后变化、方案 A/B、错误/正确。
- 左右分屏或上下分屏，光线与角度保持一致。
- 不要在图片中直接生成复杂中文，改为预留文字区。

Prompt 片段：

- `左右对比构图，左侧为改造前，右侧为改造后`
- `相同角度和光线，差异清晰`
- `预留标签位置，不生成文字`

## 知识卡片构图

- 背景简单，层级清晰。
- 适合图标、色块、编号、留白。
- 如果模型中文文字能力不稳定，要求“不生成文字”，后期再叠字。

Prompt 片段：

- `信息图卡片布局，三段式结构，留白充足`
- `简洁图标和色块，不生成真实文字`
- `适合后期添加中文标题和要点`

## 负面约束

通用负面约束：

- `不要乱码文字`
- `不要水印`
- `不要品牌 Logo`
- `不要畸形手指`
- `不要过度磨皮`
- `不要杂乱背景`
- `不要夸张滤镜`
