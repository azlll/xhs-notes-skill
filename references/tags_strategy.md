# 标签策略

## 数量建议

- 默认 8-12 个标签。
- 搜索型内容可 10-15 个，但不要堆砌无关热词。
- 强品牌、强地点、强活动内容可加入 1-3 个真实品牌/城市/活动标签。

## 标签分类

- 赛道词：美食、穿搭、家居、收纳、知识卡片、通勤、旅行。
- 场景词：早餐、租房、小户型、上班、周末、夏天、开学。
- 人群词：新手、上班族、小个子、梨形身材、学生党、独居。
- 痛点词：显矮、显乱、不会搭、没时间、预算有限、翻车。
- 长尾词：番茄鸡蛋面做法、通勤包收纳、小户型玄关改造。
- 内容形态词：教程、清单、避坑、测评、复盘、图文笔记。
- 品牌/地点词：仅在真实出现或用户明确提供时使用。

## 组合规则

默认组合：

```text
2-3 个赛道词
2-3 个场景词
1-2 个人群词
1-2 个痛点词
1-2 个长尾关键词
0-2 个品牌/地点/活动词
```

优先级：

1. 保留用户核心关键词。
2. 补充搜索意图强的长尾词。
3. 加入与图片内容一致的场景词。
4. 删除无关泛热词。

## 标签公式

### 通用发布公式

```text
2个赛道词 + 2个场景词 + 1个人群词 + 1个痛点词 + 1个情绪词 + 1个长尾搜索词 + 0-2个节点/本地/品牌词
```

### 搜索流量公式

```text
核心关键词 + 细分关键词 + 人群关键词 + 问题关键词 + 内容形态词 + 长尾搜索词
```

示例：

`#通勤包收纳 #包包收纳 #上班族收纳 #通勤必备 #收纳教程 #通勤包怎么收`

### 节点借势公式

```text
赛道词 + 节点词 + 季节词 + 场景词 + 人群词 + 情绪词 + 长尾搜索词
```

示例：

`#端午出行 #夏日穿搭 #周末计划 #小个子穿搭 #松弛感 #端午去哪玩`

### 本地探店公式

```text
城市词 + 商圈/街区词 + 品类词 + 场景词 + 口味/体验词 + 内容形态词
```

示例：

`#柳州螺蛳粉 #路边摊美食 #夜市美食 #酸辣口 #城市烟火气 #美食探店`

### 情绪内容公式

```text
场景词 + 情绪词 + 生活方式词 + 人群词 + 内容形态词 + 长尾共鸣词
```

示例：

`#城市黄昏 #治愈文案 #慢慢变好 #打工人日常 #生活感悟 #今天也要好好生活`

### AI 创作公式

```text
AI工具/形态词 + 风格词 + 主题词 + 内容形态词 + 风险提示词
```

示例：

`#AI绘画 #AI创作 #名画二创 #设计灵感 #小红书封面 #AI生成图片`

## 标签自检

- 每个标签都能对应正文或图片内容。
- 不使用和内容无关的热门标签。
- 不用侵权、误导或虚假品牌标签。
- 不把医疗、投资、功效等高风险词包装成标签引流。
