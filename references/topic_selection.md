# 主题确认与选题规则

## 目标

在生成小红书最终笔记前，先让用户确认内容主题，再基于已确认主题生成选题建议。主题确认决定“写什么”，选题建议决定“从哪个发布角度写”。

## 硬性规则

- 所有新任务都必须先做主题确认。
- 未确认主题不得生成最终笔记、标题、正文、标签或可复制发布区。
- 即使用户说“直接生成”“不要问问题”“快速出稿”，也必须先确认主题。
- 主题确认完成后，再做缺项补问、智能选题、主题强相关联网搜索和成稿。

## 主题确认

### 有图片时

根据图片可见事实和合理推断生成 3-5 个主题选项：

- 每个主题候选包含主题名称、适合人群、内容价值、图片依据、风险边界。
- 图片依据只能来自可见主体、场景、构图、光线、文字、氛围或用户补充信息。
- 不把店名、城市、价格、品牌、功效、身份、真实体验等不确定信息写成主题事实。
- 最后一个选项必须是 `我想自己输入主题/其他主题`。

### 无图片时

根据用户文字意图生成 3-5 个主题选项：

- 每个主题候选包含主题名称、适合人群、内容价值、文本依据、风险边界。
- 如果用户文字很泛，优先给出日常、经验、攻略、探店、带货等稳妥主题候选。
- 最后一个选项必须是 `我想自己输入主题/其他主题`。

### 自定义输入主题

- 用户选择自定义输入主题后，以用户输入为已确认主题。
- 不要把用户自定义主题改写成另一个主题；只能做轻微错别字修正或语义澄清。
- 若自定义主题含高风险承诺、虚假事实或敏感内容，先提醒风险并请求改写主题。

## 主题候选格式

```markdown
我先确认主题，选项编号即可，也可以直接输入你的主题：

1. [主题名称]
   - 适合人群：
   - 内容价值：
   - 依据：[图片依据/文本依据]
   - 风险边界：

2. [主题名称]
   - 适合人群：
   - 内容价值：
   - 依据：[图片依据/文本依据]
   - 风险边界：

3. 我想自己输入主题/其他主题
```

## 选题建议

用户确认主题后，再生成 3-5 个选题建议。选题不是主题本身，而是围绕同一主题的发布角度。

每个选题建议包含：

- 选题名：一句话概括发布角度。
- 适合方向：带货、攻略、经验、探店、旅游或日常。
- 目标人群：谁会被这篇笔记吸引。
- 爆点：点击、收藏、评论或共鸣的主要原因。
- 风险边界：不能编造或需要审慎表达的信息。

默认推荐一个最稳妥选题，但在最终成稿前要求用户确认选题；若用户明确授权“用推荐选题”，则采用推荐选题继续。

## 选题候选格式

```markdown
已确认主题：[主题]

我给你 3 个选题方向，选一个继续：

1. [选题名]（推荐）
   - 适合方向：
   - 目标人群：
   - 爆点：
   - 风险边界：

2. [选题名]
   - 适合方向：
   - 目标人群：
   - 爆点：
   - 风险边界：

3. [选题名]
   - 适合方向：
   - 目标人群：
   - 爆点：
   - 风险边界：
```

## 与联网搜索的关系

- 主题确认前，可以用联网辅助生成更好的主题选项，但不能把未经证实的热点写成事实。
- 生成标题前必须基于已确认主题和选定选题执行主题强相关联网搜索。
- 只采纳与主题、图片或用户文本高度相关的实时新闻、节点、热梗、平台表达和热门标签。
- 不为了蹭热点扩大到无关新闻或泛娱乐热点。
