# 热梗热词更新规则

## 何时需要更新

遇到以下情况，应先更新或校验热词，不直接套用旧词库：

- 用户要求“最新热梗”“今日热词”“本周小红书热门词”。
- 内容需要蹭节点：节日、开学、毕业季、考试、618、双11、春节。
- 内容面向强时效赛道：娱乐、影视综艺、AI 工具、短视频挑战、明星热点。
- 词库中的词看起来和目标人群年龄、平台语境不匹配。

## 推荐校验流程

1. 明确平台：小红书优先，其次按用户要求看抖音、微博、B站、公众号。
2. 明确时间：今天、本周、本月、季度、年度。
3. 明确赛道：美食、穿搭、家居、AI、知识、情绪、旅行等。
4. 搜索时组合关键词：`小红书 + 年份/月份 + 赛道 + 热词/热梗/趋势词`。
5. 只采用能理解含义和使用场景的词；不确定含义就不使用。
6. 写入正文前做合规检查，尤其是医疗、金融、未成年人、身份群体相关内容。

## 更新记录格式

当用户要求长期沉淀新热词时，可按以下格式追加到 `references/trend_keywords.md`：

```markdown
### YYYY-MM 平台/赛道

- 热词：
  - 含义：
  - 适合场景：
  - 不适合场景：
  - 示例标题：
  - 来源：
```

## 选词优先级

1. 用户明确给出的热词。
2. 近期可验证的平台热词。
3. 长期稳定的内容情绪词，如松弛感、情绪价值、活人感。
4. 通用句式模板，而不是具体梗词。

## 降级策略

如果不能确认热词是否仍流行：

- 改用更稳的表达：`最近很有讨论感`、`很适合做封面钩子`、`更容易产生共鸣`。
- 把具体梗改成语气：轻松、自嘲、反差、治愈、松弛、真实。
- 不在标题中使用不确定热词，可放在评论钩子或备选标题里。

## 风险提醒

- 热词不是流量保证，不写“用了就爆”。
- 对平台趋势的判断必须保留不确定性。
- 涉及品牌营销时，不把第三方趋势报告写成官方平台规则。
- 如果来源是商业报告、转载站或论坛，应标注为“参考”，不要作为唯一事实依据。
